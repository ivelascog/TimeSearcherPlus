Benchmark FPS Fluidez — TimeWidget

Mide los fotogramas por segundo reales durante renderizado continuo. Refleja directamente la fluidez que experimenta el usuario al interactuar con el widget.

¿Qué mide este benchmark?
Ejecuta un bucle de animación requestAnimationFrame llamando a ts.renderDirect() en cada frame. Tras cada frame se llama a ts.syncRenderer() para forzar que la GPU complete el trabajo antes del siguiente frame (comparación equitativa entre Canvas 2D y WebGPU).
Umbrales de fluidez: ≥ 45 fps = fluido · 17–44 fps = visible · ≤ 16 fps = inutilizable para interacción.
La ventaja de WebGPU sobre Canvas 2D crece con N: el paralelismo masivo de la GPU compensa el overhead de la API a partir de ~10k series.
Ambos renderers procesan todas las series y sus puntos, sin submuestreo.
